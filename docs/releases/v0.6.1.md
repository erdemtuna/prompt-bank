# Prompt Bank 0.6.1

Analytical prompts now lead with the result, recommendation, or decision implication and keep supporting evidence close to each claim.

## Improvements

- Updated the investigation, review, planning, comparison, summary, code-explanation, and root-cause prompts with answer-first structures tailored to each workflow. ([`e8425f9`](https://github.com/erdemtuna/prompt-bank/commit/e8425f9910f14fed1b7085923bf6857f32fc8e6a))
- Standardized technical-design diagrams on fixed semi-formal Mermaid, C4, and UML semantics. System architecture now defaults to a C4 Container view, and **Data flow and trust boundaries** replaces the previous API/data-flow view. The guidance defines element limits, status notation, shapes, arrows, legends, unresolved facts, and render-review expectations. ([`e8425f9`](https://github.com/erdemtuna/prompt-bank/commit/e8425f9910f14fed1b7085923bf6857f32fc8e6a))

## Documentation

- Added authoring guidance for readable analytical output and self-contained HTML reports: copied prompts should request inline SVG for generated diagrams, while PNG remains appropriate only for pre-existing local image artifacts. Prompt Bank itself remains copy-only and does not generate reports or diagrams. ([`e8425f9`](https://github.com/erdemtuna/prompt-bank/commit/e8425f9910f14fed1b7085923bf6857f32fc8e6a))
- Refreshed the README hero after v0.6.0 and updated it again for v0.6.1 to show the installed **Investigate a Topic** workflow with its current answer-first and semi-formal diagram guidance. ([`bf36993`](https://github.com/erdemtuna/prompt-bank/commit/bf369930cc2e6114a16ec4f2089ef132740c6636), [`e8425f9`](https://github.com/erdemtuna/prompt-bank/commit/e8425f9910f14fed1b7085923bf6857f32fc8e6a))
